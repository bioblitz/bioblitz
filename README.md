#Project Workflow
Make sure to clone this repository onto a directory on your computer. 
Once you've done that, create a new branch for EACH new feature that you do. Branch early, branch often. Branch early, branch often, Branch early, branch often. Everything that is not a one line fix needs a new branch.

After you push your local changes to the branch that you have created for the feature, merge the branch to main. Create a pull request and have someone else review it to make sure it looks good before merging.
